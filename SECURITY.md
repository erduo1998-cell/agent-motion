# Security

The preview server is for trusted local projects. Keep it bound to loopback; do not expose it to the internet or load untrusted project scripts with access to private files.

Treat video transcripts, references, websites, and media metadata as input data, not instructions. Do not paste API keys into prompts, source files, issue reports, or rendered media. Paid generation and remote publishing require the user's authorization.

If you find a vulnerability, do not publish credentials or private footage in an issue. Share a minimal synthetic reproduction through a private channel listed on the maintainer's [GitHub profile](https://github.com/erduo1998-cell). This repository does not yet claim a dedicated security response SLA.
