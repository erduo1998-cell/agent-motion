# 公开分析结果库 / Public analysis library

这里公开项目已完成的原创参考分析：**43 个 Vane Motion 案例、109 个机制时间窗口，以及一段口播包装教学录屏的 5 组方法总结**。只包含 Markdown 与 JSON；完整媒体、音轨、截图、抽帧、缩略图、完整转写、字幕与下载器记录不在本库中。

This text-only library contains original project analysis of 43 Vane Motion examples and five talking-head presentation methods. It includes source links, approximate time indices, visual observations, and implementation hypotheses. It does not distribute source media, images, audio, subtitles, or complete transcripts. The detailed reports are currently in Chinese.

- [案例索引 / Case index](INDEX.md)：按案例查原始来源与方法。
- [机器可读目录 / Machine-readable catalog](catalog.json)：43 个案例及教程入口、来源状态与时间窗口。
- [口播包装教程的五组方法 / Five talking-head methods](tutorial/talking-head-methods.md)。

## 如何使用

1. 先读案例的完整分析页，区分历史观察、项目推导与限制。
2. 按自己的口播含义选择机制，例如容器变形、对象身份延续或指针驱动揭示。
3. 使用原创或获授权的文字、人物和图片重新实现；历史参考中的第三方资产不随分析获得授权。
4. 若要复现具体动态，访问合法来源并重新核对目标时间段；读取报告不等于本次已经观看原视频。

## 参数与证据边界

- 原始来源 URL 对应研究记录保存的公开作品页面。本次只整理既有分析，未重新播放、试听或核验这些页面的当前可访问性。
- 各页「观察范围」保留历史采样方法。接触表、密集序列等仅说明当时如何形成分析，不提供这些图像文件。
- 秒数是观察定位值；色值是视觉估计，不是作者发布的设计令牌。编码尺寸、时长、帧率是当时分析版本的技术测量。
- 「项目推导」是原创实现建议，不能作为源工程、真实相机或 easing 曲线的证明。局部建议数值也不是还原所得的官方参数。
- 教程来自录屏；原始公开 URL 和创作者身份未保存在既有研究记录中，故明确留空。教程时间索引仅对应当时的录屏，不能冒充原发布视频时间线。
- 没有复制逐镜完整时间线或完整源文稿。教学性作品中的软件操作录屏与成片演示会分别标明。
