# 转场连续性：T01–T06

转场同时影响注意力、对象身份、空间和节奏。前后镜头一起设计、一起播放检验；只有单镜头好看不能证明衔接成立。整段时间结构见 [sequence-rhythm.md](sequence-rhythm.md)，来源编号见 [sources.md](sources.md)。

本文“剪切、断开、例外”是通用方法，使用范围由 [项目转场要求](transition-construction.md) 约束：本项目口播跨版式默认必须连续交接，仅本次用户明确指定硬切才在对应范围改变。不能把通用例外当作取消具体要求的授权。

## T01：先确定内容关系，再选择转场

- **触发**：镜头之间全体退场、空白、全体入场，或不知道该套哪个转场。
- **动作**：判断相邻内容是继续、展开、比较、因果、并列还是新章节。需要连续时选最有意义的接力线索：同一对象、特征形状、位置、方向、颜色角色、结果或声音。
- **验证**：只看交接能否追踪前一焦点交给了什么？线索是否真正说明内容关系？去掉效果后若关系更清楚，应重新设计。
- **修复**：减少共享对象，保留最有辨识力的一项；让下一镜头从它的动作或落点继续。无共享关系时用清楚的剪辑建立新主题。
- **例外**：章节分隔、反转、对照和蒙太奇可以明确断开；不要求每镜形变、共享元素或伪一镜到底。
- **依据**：MO-C、MO-D；形状、声音与叙事剪辑接力为本 Skill 推导。

## T02：连续动作检查状态与速度接缝

- **触发**：同一对象由两个 tween、两个镜头、生成段或动画控制器接力。
- **动作**：先声明接缝是连续、停顿、遮挡切换还是硬切。承诺连续时对齐最终画面中的位置、尺度、朝向、外观、层级，以及运动切线与速度趋势。
- **验证**：检查交接前后各 1–2 帧，并正常速度连播。端点值相等不代表视觉连续；应穿越的物体是否意外零速、折返、瞬移或改变尺寸？
- **修复**：合并轨迹、明确入/出速度、调整镜位或把接合藏在有意义的遮挡中。连续位置是基础；需要光滑穿越时再检查切向速度，容差按项目设定。
- **例外**：碰撞、明确硬切和设计的停顿无需满足速度连续；不要为了数学平滑削弱冲击或叙事切换。
- **依据**：MO-A、MO-C；跨镜头端点与速度验证为本 Skill 工程推导。

## T03：一致的是方向含义，不是所有运动方向

- **触发**：重复进出场、来回推进、相向运动、换镜位后物体似乎突然倒退。
- **动作**：记录前进、返回、展开和收起等语义对应的运动逻辑；区分世界方向与屏幕方向。需要反向时让它表示返回、抵抗、冲突、重定向等意图。
- **验证**：同一意义是否可预测？相机旋转或切面是否让持续动作在画面里突然反向？新方向是否已有观众可理解的提示？
- **修复**：调整镜位/轨迹、增加可读的转向过程或中间镜头；优先修真正造成错觉的控制层，不同时乱改对象与相机。
- **例外**：相向比较、碰撞、汇聚、爆炸和反拍可同时存在多个方向；不把“同向入场”作为通用验收线。
- **依据**：MO-C、MO-F；世界/屏幕方向与相机复核为本 Skill 推导。

## T04：转场过程也要有可读布局

- **触发**：交叉换位、形变、放大、透明叠层或文字遮罩揭示。
- **动作**：检查起末状态及交叉、最大过冲、最大重叠时刻；为晚出现内容预留空间。需要临时隐去次要元素时保留足够的身份与注意力线索。
- **验证**：有没有非设计的穿字、压住重点、轮廓粘连、透明叠脏或遮罩错层？结合 [L04](layout.md#l04检查运动中的占位而不只检查关键帧中心) 看最终画面占位。
- **修复**：改路径、时间差、前后层级、遮罩或临时隐藏次要内容；图形跨淡可改为颜色/形状插值，按所需效果选择。
- **例外**：有意叠印、混色、碰撞或遮挡可成立；不能只凭包围盒相交判错，也不能用有意混乱豁免必需信息的阅读窗口。
- **依据**：MO-D、MO-F；危险时刻采样与占位验证为本 Skill 推导。

## T05：联合设计前一镜头的退出与下一镜头的进入

- **触发**：每镜各自漂亮，串起来却重启、失重、方向跳变或节奏断裂。
- **动作**：把前镜后段、转场、后镜前段作为一个设计单元；记录交接主体、注意力落点、镜头运动、空间基准与后镜的首个可读状态。同一时刻的最终变换要有明确控制/合成归属，避免独立时间线互相覆盖；允许有序的父子、约束与混合。
- **验证**：连播至少覆盖这一单元，并放回完整目标片段复核。对象自身、相机和屏幕文字的组合运动是否让焦点飞出/漂移？观众是否要无理由重新寻找主体？
- **修复**：保留或明确替换空间/视觉基准，协调两侧动作幅度和时机；必要时重写两个镜头的边界，而不是单加一个遮罩覆盖问题。
- **例外**：有意跳跃、断裂和重新定位可以服务新章节；须是内容决定，不把每镜归零当自动模板。
- **依据**：MO-C、MO-D、MO-F；跨镜头设计单元与控制权约束为本 Skill 推导。整体节奏见 [sequence-rhythm.md](sequence-rhythm.md)。

## T06：循环检查周期接缝及真实播放

- **触发**：环境循环、加载动画、无缝背景、片尾回到片头或循环片段嵌套。
- **动作**：声明周期与是否允许等待后重启；检查周期边界的画面状态、运动方向和速度。有音轨时另查声音接点，不要求为循环补音乐。
- **验证**：正常播放至少两轮；检查闪动、意外停车、多停一帧、重置曝光或模糊方向。首尾同画面不代表动势连续。
- **修复**：使用周期函数、匹配端点切线、处理重复首尾样本造成的额外停帧，或在合理遮挡处重置。技术重置与设计停顿分开记录。
- **例外**：有意等待、分段循环和低帧率风格可不连续；必须与预定风格一致。截图不能证明循环通过，未播放需如实说明。
- **依据**：MO-A、MO-F；首尾与多轮播放检查为本 Skill 工程推导。
