# 运动与节奏：M01–M06

先理解整段的时间结构，再设计局部运动。没有音乐也能按信息变化、动作因果和停顿建立节奏；有口播或配乐时采用对应时间基准，见 [sequence-rhythm.md](sequence-rhythm.md)。不要求补音乐，也不要求所有动作踩拍。

来源编号见 [sources.md](sources.md)。以下动作与验收步骤是本 Skill 对来源的工程化推导；品牌曲线、UI 时长不是普遍硬规则。

## M01：先定动作目的与时间预算

- **触发**：给对象或镜头加动效，或片段动作很多但内容不清楚。
- **动作**：说明动作表达的出现、归属、因果、比较、力度或情绪；标出前态、后态与关注对象。把对象表演时间放进镜头的信息预算，再检查前后镜头如何接上。
- **验证**：正常速度看完整目标片段，动作是否让观众理解所需变化？若删除某动作，内容或表达是否有实际损失？不能用已熟悉脚本代替初次观看判断。
- **修复**：减少无关位移/旋转，补出真正状态变化；超时先收敛动作和信息量，不把所有动画一起加速。
- **例外**：氛围片、音乐视觉和形式实验可以把情绪或节奏定为目的。微交互毫秒 token 不能直接决定视频镜头的秒级叙事长度。
- **依据**：MO-B、MO-G；镜头时间预算与全片检查为本 Skill 推导。

## M02：联合检查时间、路程与逐帧间距

- **触发**：同一时长下有的物体蹿动、有的拖沓，或换画幅/镜位后速度失衡。
- **动作**：记录运动路程、时长与关键停点；看等时间采样的位置间距。3D 对象同时检查最终相机投影后的屏幕速度，不只看世界坐标。
- **验证**：查看运动路径和速度曲线，再正常播放；峰值速度、加减速位置是否符合重量、行程与可读要求？缩放或推镜是否让小动作变成大范围扫屏？
- **修复**：联合改时长、路程与曲线；不同尺寸和路程分别定时，然后协调到同一段落。不要只换一个 easing 名称。
- **例外**：编舞可以让不同距离的对象同拍到达；相同 duration 不必相同速度。恒速、导轨和连续扫描可以使用线性运动。
- **依据**：MO-A、MO-B；投影后的速度检查为本 Skill 推导。

## M03：按落定、穿越、进出场选择曲线

- **触发**：设置插值、应用动效预设，或对象在每个关键帧前后都停一下。
- **动作**：标注每段是落定、穿越、离场、附近待召回或冲击。落定通常需要可控减速；持续运动保留进出速度；无理由不在可见画面里提前停车。
- **验证**：检查中间关键帧的零速、反弹、折返与拖长尾部。对连续段结合 [T02](transitions.md#t02连续动作检查状态与速度接缝) 检查端点趋势，不能只看曲线“够弯”。
- **修复**：删多余停点，分别调入/出速度或合并轨迹。AE 全选 Easy Ease 会把所选关键帧速度设为 0，不是持续运动的通用修复。
- **例外**：机械棘轮、定格、冲击、惊停与明确节拍定点可以突然改变速度；跟随用户输入的实时 UI 不为曲线造型拖延。
- **依据**：MO-A、MO-B；“所有动作必须缓动”不继承为通用要求。

## M04：让路径、重量和次级动作服从对象设定

- **触发**：弧线、分轴、回弹、挤压、随动、拖尾或产品落地。
- **动作**：先确定材质、约束、受力与风格，再决定路径和预备动作。投掷、铰链、导轨和网格重排可以用不同轨迹；次级动作跟随明确的因果或从属关系。
- **验证**：物体是否像设定的材料？转弯是否可跟随？变形是否破坏产品/字形特征？余振是否抢走下一件事的关注？
- **修复**：删冗余控制点、调切线或转弯速度，降低无来源弹性与尾部幅度；需要强调时也可改变灯光、构图或时间。
- **例外**：弹性物可以弹，金属可整体受冲击后落定；每个动作不必都有预备、反冲和拖尾。单轴路径、禁弹跳或强制弧线均不是通用法则。
- **依据**：MO-C、MO-E、MO-H。

## M05：根据理解顺序编舞，不机械逐项排队

- **触发**：多个元素同刻抢动，或逐个演完造成整体拖长。
- **动作**：先排理解顺序，再定起始时间、重叠区与归组。同一比较组可整体出现；需要引导时才错峰。已有主体、背景、镜头与文字的动作要放到同一时间线上看。
- **验证**：正常播放一次能否跟上关注顺序？最后一项是否因数量增加而迟到？相机与对象同时运动时，是否增加了无关竞争？
- **修复**：按组错峰，减少单项时长，加入必要重叠或让背景先稳定。不要给大量元素机械累加相同延迟。
- **例外**：整体揭幕、同步比较、齐奏、汇聚和爆炸可以同时发生；不要求永远三层动效或全部元素错开。UI 的 20 ms stagger 是具体场景建议。
- **依据**：MO-C、MO-D、MO-E；跨镜头主次结合 [sequence-rhythm.md](sequence-rhythm.md)。

## M06：保留可用的阅读与认知停顿

- **触发**：标题刚落定便离开，数字未稳已转场，或整片没有活动强弱变化。
- **动作**：从内容真正可辨认/可阅读时计算可用停留，结合 [L05](layout.md#l05可读时间从文字真正可读时开始计算)。在完整片段中安排强调、理解和释放；无音乐以信息与动作完成建立节拍。
- **验证**：按实际有声/无声用途正常播放；必需信息是否来得及理解？连续镜头是否无理由反复归零、重复同一种进退场？动的主次与停的时机是否清楚？
- **修复**：提前入场、缩短表演、降低阅读区的干扰、推迟退场；必要时重分信息。固定总时长时先协调内容与镜头预算。
- **例外**：阅读段允许轻微环境运动；有意不可读的纹理字不按正文计时。静止、规律重复和无配乐都可以成立，不强制每拍变化。
- **依据**：MO-B、MO-F；无音乐节奏和全片时区划分为本 Skill 推导，详见 [sequence-rhythm.md](sequence-rhythm.md)。
