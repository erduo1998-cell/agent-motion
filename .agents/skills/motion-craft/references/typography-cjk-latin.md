# 中英文排版：文字结构决定布局和动效单位

适用于 L01–L06 以及所有文字动画。先记录语言/地区、实际字体、横排/竖排、文字角色和观看尺寸。中文、英文、混排需要分别做样张，不能共用按字符数计算的自动字号。

依据：LANG-A（W3C 中文排版需求，当前是草案）、LANG-B（W3C 断行说明）、LANG-C（Adobe CJK 字体）、LANG-D（Unicode 文本分段）、LAY-B（IBM 字体排版）。以下视频执行与例子为本 Skill 推导；不把书籍排版体例直接变成视频硬规则。

字体选型按 [字体组合与海报](typography-poster-pairings.md) 在包含人物、素材和真实文字的完整构图中比较有实质差异的方向，确定主标题、说明和数字角色；只替换同一句话的字体、已加载和无缺字均不代表选型完成。用户锁定或已认可的字体系统按其范围继承。

## 分开处理这些变量

| 变量 | 中文 | 英文 | 混排与修复 |
|---|---|---|---|
| 字面与字宽 | 汉字外框近似方形，真实字面和视觉重量因字体而异 | 比例字宽、大小写、升降部改变可见轮廓 | 同样字号/字重名称不代表同样视觉大小；在同一画面比较真实字形后调字号与基线 |
| 行内间距 | 不靠词间空格划分词语 | 词距与字偶间距作用不同 | 汉字与西文/数字边界单独处理；不要把英文单词内部按汉字均匀拉开 |
| 断行 | 有多处可断点，但还要照顾标点及语义 | 优先词边界，适当语言规则下才连字断词 | 保护产品名、数值和单位组成的阅读单元；长 URL/代码使用其专门断行策略 |
| 标点 | 开闭标点、不可拆的符号组合需检查，简繁及地区体例有差异 | 依英文文本语法处理空格、引号和标点 | 不把所有标点全局转换为半角或全角；书名、代码和产品标识保留原样 |
| 对齐和行距 | 可左齐、居中、网格排版；视内容与风格决定 | 可左齐、居中等，不因来源品牌规定就一律左齐 | 按可见字面、重音符号和实际行距试看；不能给两种语言统一套一个行高倍数 |
| 动画单位 | 优先词组、短句或语义块 | 优先单词、短语或句子 | 先分语义，再按强调需求拆字；字形数量不同，不共用同一逐字延迟预算 |

### 文字定稿前的短检查

1. 用实际完整文字排版，确认字体已加载、字库覆盖、地区字形符合项目。缺字或 fallback 可能改变整行宽度；不能在替代字体状态下锁定位置。
2. 实际测量整段字形、换行结果与包围范围，保留连字/字偶间距。三维文字也要检查实际字面和挤出后轮廓，别只用字符长度乘字号。
3. 在拟采用的中文断行体例下检查行首闭标点、行末开标点及不可拆符号。示例常见问题：第二行仅剩“，更快”，或“（”被留在上一行末尾。用调整行宽或语义断行修复，不粗暴删标点。
4. 检查 `MiniMag X3`、`Three.js`、`99.9%`、`240 fps` 等阅读单元。`240 fps` 的空格形式依项目体例，动画和换行不应把单位丢开；这不是宣称所有数值/单位之间都不得有空格。
5. 中西边界用排版能力或受控 run 间距解决；若采用文本空格就检查实际字宽，避免与自动间距双重叠加。品牌名内部不要随意插空格。
6. 翻译后重新排整段、重新评估可读时长。保留风格和语义关系，不强求中文英文同一行数、逐字一一对应或逐帧同时落点。

## 动态文字的额外约束

**不要把每个 Unicode 代码单元当成独立字形。** 表情、变音符号和组合字形可能跨多个代码点；以宿主支持的字素/字形分段为基础，再组成语义组。分割后不得丢掉英文词距、kerning 或语言塑形。当前宿主做不好时，使用整词/整行遮罩或保留成形后的字形位置。

**语义组先于逐字炫技。** “让复杂流程 / 变得清楚”与 “Make complex workflows / clear”可对应两个语义节拍，各自排版。中文前半句不因只有几个字就闪过；英文也不因字符更多而把总进场拖长一倍。逐字动画适合少量强调字、拼写展示和特定风格，不默认用于全部说明文字。

**选定阅读段后保护布局。** 揭示文字时预留最终完整行宽；滚动数字为最终位数、符号和单位预留空间。若计数跳动导致其后单位左右抖动，可固定数字容器或使用合适的等宽数字特性，不能误把所有正文都换等宽字体。

**中英文并排不是自动等权。** 双语同等重要时，给二者足够阅读时间和清楚分区；英文只承担辅助译名时可降低其视觉权重。由任务定义角色，不把中文必大、英文必小当法则。

**竖排另开分支。** 用真正的竖排支持，检查标点、拉丁字母方向和数字配置；不要把整行横排旋转 90° 就称为中文竖排。缺能力时先验证替代实现，必要时说明限制。

## 可直接用于检查的样本文案

- 中文：`把复杂流程，变成清楚的三个步骤。` 检查行首标点、语义分组、稳定阅读时间。
- 英文：`Make complex workflows easier to understand.` 检查词距、单词断裂、最后一词孤立、字偶间距。
- 混排：`用 Three.js 呈现 3D 空间，支持 MiniMag X3。` 检查产品名、基线、边界间距与末行。
- 数值：`成功率 99.9%｜延迟 12 ms` 检查计数期间符号/单位是否漂移。

这些是测试输入，不是所有项目必须显示的固定文案。语言排版的合格不代表动画节奏合格，还需按真实时长播放。
