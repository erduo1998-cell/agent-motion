# 验证：让成片证明设计成立

此页规定本项目制作的检查方法，按本次内容适用，不是普适美学定律。新制完整影片必须检查全片；局部修订检查受影响范围及相邻衔接，不要求完整镜头卡、转场卡或检查台账。条目中的可选采样方法不免除实际输出的动态观看与有声任务的试听。

## 最小闭环

1. 说明观众应看懂什么、跟随谁；标出文字阅读窗口和最可能失败的地方。
2. composition 先做实际画幅、真实字体/文案的代表构图；完整读取 animation 后，做通开场和最难关系段的起始、变化、阅读及相邻交接，随后逐段扩展，不能先排完整片静态页。
3. 看完整正常速度预览，再看风险帧；修最影响理解的问题，重查受影响部分。
4. 全片扩展后查看实际交付文件的完整正常速度预览，有声任务试听实际音轨。交付区分已观察结果、程序检查和未验证项；代码成功、日志无错不等于画面成立。发现原景误描边、换背景漏描边、悬浮/取景失败、压盖或重复翻页式动画必须先修复；必要观看/试听未完成时只能标为待检查预览，不能宣布成片完成。用户明确要求未经检查的原稿时遵守其范围。

## 证据各自证明什么

| 证据 | 能证明 | 不能单独证明 |
| --- | --- | --- |
| 实际输出视频、正常速度播放 | 注意力、节奏、衔接、阅读与音画关系 | 每一帧都无几何异常 |
| 起始、关键变化、终态及风险帧 | 特定时刻的构图、遮挡、字形与姿态 | 速度顺畅、全程可读 |
| 时间线、曲线、轨迹 | 对象、参数、路径和时间如何设置 | 观众在成片中确实看见该效果 |
| 包围盒、投影和像素诊断 | 定位越界、异常重叠、消失等疑点 | 自动认定“高级”“拥挤”或“空间感足够” |
| 辅助斜角、调试视图 | 排查场景结构与深度配置 | 替代交付相机的空间证据 |

中间证据帧不等于必须增加中间源关键帧。两个源关键帧也能产生完整好运动；不要为了通过诊断而加出无意停顿。

## 覆盖整个时间轴

- 有廉价几何接口的短片，可遍历每个实际输出帧，检查必须可见元素在指定阅读时段内是否越界、消失或产生禁止重叠。
- 高成本工程可用覆盖全时长的规则抽样，加进出场、过冲/旋转/缩放极值、最多内容并存、遮挡交换、相机接近对象、字幕换行和转场事件抽样。
- 高速小物体、短促遮挡、已经报错的区间，局部加密到逐输出帧。少数截图只能报告样本结果，不能宣称全程零碰撞。
- 检查真实字幕、前后两个镜头和全局叠加层同时存在的区间，不能只查各镜头终态。
- 以实际输出帧数和宿主时间基准找首末帧；零基输出 N 帧通常检查第 N−1 帧。`duration` 可能是右端不含的边界。
- 慢放用于找原因；正常速度用于判断观众体验。至少看一次最终完整预览。

## 排版：中文、英文和混排分别看

- 用实际字体完成加载后的结果检查，确认缺字和回退字体没有改变字重、字宽与换行。
- 中文看词组/语义分行、标点禁则、括号引号、短孤行；不要按固定字符数机械切分或逐字弹跳。
- 英文看完整单词、长词、词距、大小写、连字和断词；不得为装入版面随意压窄字形。
- 混排看视觉字号、基线、字重、数字与单位、标点、技术标识和长网址；中文行宽经验不能直接套英文。
- 长串需显式采用适合任务的换行、分区或分时呈现；涉及删改文案时遵守原任务授权。
- 看标题、正文、注释与字幕的角色，以及运动中是否相互穿越或抢读；最终排列整齐不能抵消中途拥挤。
- 在实际观看尺寸检查可读性；大屏高分辨率静帧可读，不代表手机正常速度可读。
- 文本外框不是字形全貌：描边、阴影、遮罩、透视和运动模糊可能改变可见范围。
- 字体选型检查本次真实候选画面，确认已试过默认黑体/宋体之外的显示家族，并按字形重做完整构图；检查语气、辨识度、角色与层级，不能只写“比较过”或仅检查加载/缺字。逐项看组内距、组间距、卡片内边距，以及标签与人物描边的距离，不以零碰撞代替间距设计。
- 原页正文、提取结论和新增说明不能在阅读阶段叠成两层抢读文字；检查最密状态和切换中间态，不能只看干净的开头截图。

## 空间、镜头与转场一起验证

- 先确认主焦点与前后关系在实际输出可见；二维素材/正交实现不因缺少Z轴而失败，但不能豁免全片空间组织和人物卡片悬浮。
- 交付相机必须显示所设计的空间线索，例如遮挡、表面朝向、透视变化、视差或光影关系；不同 Z 值本身不算证据。
- 区分对象方向、相机方向与屏幕投影方向；世界中向右不一定在屏幕向右。
- 交接前后看同一主体身份、注意力位置、设备/场所关系、运动方向及速度是否按意图延续。
- 需要连续的运动不应无故跳位或刹停。冲击可有意改变速度；通用类型的硬切/章节断开不能覆盖本项目口播跨版式默认连续交接的要求，具体按 [转场规则](transition-construction.md) 执行。
- 检查交接前、内容重叠最多时、交接后，并连续播放；不能用单个漂亮转场中帧验收整段。
- 本次范围允许明确剪切时可用直接切换完成注意力接力；口播跨版式默认仍须连续交接。不必每次用遮罩、飞行或叠化；全片统一整页平移/淡入也不算完成不同语义的动作设计。
- 人物描边按背景状态双向检查：全幅/小窗保留原背景时不得有装饰轮廓边；替换背景时应有宽而清楚、不抖动的边带；局部出框只检查背后换景的轮廓。转换中不能提前描边或恢复原景后残边。抠像仍须同步，不能用撤销人物层来修复误描边。
- 人物卡片在稳定帧与移动中必须显出3D悬浮，投影/边缘受光与卡片关联；仅有圆角、矩形线或人物描边不通过。主信息清楚，非焦点景物按空间关系退出竞争，不得全局模糊。
- 每一种窗形检查真实头部、脸、颈肩和必要手势：人物视觉中轴居中，比例适合窗口，头顶有余量，不能框居中而人偏在边上。检查全幅起点、缩窗中途、最窄形状、源人物运动极值、角落终态及回全幅；不得随机裁切或用静帧居中代替全段检查。

## 无音乐、仅口播与后加音乐

- 对承担说明功能的画面，可先静音诊断其关系、变化和结果是否可跟随，再按真实声音条件判断整体。音乐驱动、口播依赖或纯氛围片不强求静音后传达全部意义，见 [整体空间与节奏](sequence-rhythm.md)。
- 无配乐的任务，靠动作间隔、快慢、停顿、信息显隐和视觉重音组织节奏，不擅自加音乐掩盖问题。
- 仅口播时听完整交付音轨：关键动作跟随实际语义落点，阅读状态避开同时出现过多新信息；让呼吸和停顿有空间。
- 有音乐时，先保留信息与阅读窗口，再选择可对齐的重音；不要求每个动作卡拍。
- 后加音乐优先局部适配：保护原有语义、已锁定字幕锚点和足够的阅读时间；可调整未锁定的弹性时段。若用户明确以音乐为主，按其优先级重排并复查整段。
- 只有字幕时码或没有音频，明确说明尚未做听觉验收；不得自报口播同步或音乐效果已通过。

## 程序检查的边界

- 3D 应看投影后的画面关系；世界空间不碰撞不等于屏幕不遮字。锚点可见也不等于整个对象可见。
- 用少量规则声明允许的遮挡，例如“前景可遮背景，装饰不可盖读数”；不把一切包围盒相交判成错误。
- Canvas 的 DOM 框只能证明画布大小，不能证明内部对象布局。复杂遮罩、近裁切和细长旋转物体需查像素。
- 可重复渲染的要求是同一配置下同一帧可靠复现；可用固定时间状态、种子或合法缓存/烘焙。
- 随机采样渲染可有合理噪声容差；对象位移、缺资源、换行变化不能被容差掩盖。
- 不建立一个自动分数代替审美。视觉问题用时间/帧号、可见症状和修正说明定位。
- Agent 自评不等于用户审美验收，也不必因此给每个低风险动作新增审批。

## 交付说明的最小范围

只在最终回复中简述以下真实信息，不新建检查记录文件；未完成的检查不能填成已看或已听。

```text
已看/已听：实际交付版本 [文件] 及实际覆盖范围。
已查：实际执行的检查及覆盖范围。
已修：最影响理解的具体问题。
限制：仍未验证的内容（无则省略）。
```

## 少量技术依据

Adobe 区分时间插值与空间插值；线性变化和曲线路径各有用途，自动曲线也可能产生意外回摆。不要把“禁线性”当质量门槛。[Adobe：Keyframe interpolation](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/keyframe-interpolation.html)

正交相机不会因对象远近改变其画面尺寸，投影检查也需要完整对象而非单个点。[Three.js：OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html)、[Vector3.project](https://threejs.org/docs/pages/Vector3.html#project)

指定时间定位与模拟缓存是不同层面的能力；宿主 API 以工程版本为准。Blender 模拟烘焙可支持非顺序帧渲染，不能用“所有效果必须无历史”代替正确适配。[Three.js：AnimationMixer.setTime](https://threejs.org/docs/pages/AnimationMixer.html#setTime)、[Blender 5.0：Simulation Zone](https://docs.blender.org/manual/en/5.0/modeling/geometry_nodes/simulation/simulation_zone.html)
