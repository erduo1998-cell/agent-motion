# 空间与镜头

先决定观众需要理解什么空间，再设计使这种关系可见的线索。二维、2.5D、正交和真实三维各有用途；加 Z、加阴影或动相机都不自动代表成功。

以下“验证/修复”为本 Skill 的实施推导。SP 编号对应 [来源](sources.md)；摄影规则迁移到 MG 时按内容目标使用，不当通用硬标准。

## 本项目以空间组织画面

本项目的完整动画和口播包装必须作为具有前后关系的空间设计。先确定当前主焦点、前景与背景，再决定字体、素材和运动如何进入这个空间。这里要求最终画面可见的层次，不要求把每行字挤成实体或只允许透视相机；二维素材、2.5D分层和正交图形都可构成空间，但不能把各层等清晰、等对比、等权重贴成平面。

主信息接管注意力时，让非焦点层通过遮挡、尺度、相对运动、光影或清晰度关系退出竞争。复杂实景或次要素材干扰主信息时，必须在对应层局部虚化或降低对比；主焦点与当下必读文字、脸部、证据保持清楚。焦点转交时随之调整清晰关系，不能整幅一起糊，也不强迫每帧都有模糊。平面图表/字幕本身可保持平面，仍须在全片空间里有明确角色。

在交付相机、手机观看尺寸及连续动作中检验：能直接看出谁在前、谁是焦点、人物/卡片相对什么表面存在。仅分了图层、用了Three.js、写了z值或加圆角都不能作为通过依据。空间处理不得靠缩短既有动作、统一曲线或删掉连续衔接来实现；保留 motion.md 与 transitions.md 的完整运动方法。

## S01 建立整段空间，而非逐镜堆深度

- **触发**：新片段、多镜头序列，或反馈“平、乱、不知在看哪里”。
- **动作**：选择二维信息空间、2.5D 分层或实体三维；为每个镜头记录 `world_id / 看什么 / 空间锚点 / 前后关系 / 主体动作 / 相机动作 / 与下一镜关系`。同一空间保留可认出的锚点，跨概念章节标为重置。
- **验证**：看完整目标段落，能否跟踪“现在在哪里、为什么来到这里”；稳定帧中能否指出目标关系。只统计 Z 层数无效。
- **修复**：优先重排尺度、遮挡与构图；补共同锚点或总览；无共同物理空间时明确换章，不强接飞行镜头。
- **例外**：字幕、图表、正交UI等局部对象可以是平面的，但不豁免本项目整体空间与人物卡片悬浮要求；蒙太奇可按概念关联，不必共享世界坐标。
- **依据**：SP-B、SP-D、SP-H 支持空间表示差异；SP-E、SP-F 支持空间/镜头关系；序列地图为本 Skill 综合。

小任务内联记录即可：

| 镜头 | 空间与观看目的 | 主动作/镜头 | 相邻镜关系 |
|---|---|---|---|
| A | 产品台面，认识整体 | 产品静止/固定总览 | 同空间看接口 |
| B | 同一台面，接口为焦点 | 产品静止/靠近并横移 | 同对象发生动作 |
| C | 同空间，解释插接 | 连接器进入/镜头停留 | 概念章节重置 |
| D | 二维数据图，解释路径 | 节点依因果显现/固定 | 同图继续 |

例子的台面、镜头数量和运动均不是模板要求。

## S02 用一致的深度线索和可见视差

- **触发**：需要前后层次，却像一整张贴纸；或运动时重要内容被遮住。
- **动作**：先规定谁在前、谁在后及允许遮挡窗口；按需求组合尺度、遮挡、透视、相对运动。透视相机横移时，检查分层是否真正产生相对位移。把场景文字和屏幕注释分开设计。
- **验证**：对静止场景、固定朝向的透视相机横向平移，近层通常位移更大；遮挡过程身份可追踪，必需内容在阅读窗口可见。检查遮挡最重处。
- **修复**：查是否所有层同深度，或只移动合成后的整张图；调整深度、路径或出现时间。只有目标需要透视尺度变化或固定朝向平移的深度视差时，才检查正交是否与目标不匹配；展示实体厚度先查几何与观察角度。AE 检查中间 2D 图层与预合成是否改变交互。
- **例外**：纯相机旋转、正交投影、自主运动物体不可套用“近快远慢”；揭示转场允许有意遮挡，不一律禁止重叠。
- **依据**：SP-B、SP-C、SP-G、SP-H；验证条件来自透视投影推导。

用尺寸补偿维护参考构图时，只能保持选定参考帧的投影；随后仍需看完整运动。补偿不会生成原图没有的背面。

## S03 分清投影、机位、视角与物体缩放

- **触发**：产品比例失真、推近像整页放大、相邻镜头背景比例跳变。
- **动作**：先选投影方式与观看位置，再调视角和构图；明确当前动作是相机位移、相机转向、变焦还是物体缩放。需要侧面或厚度时核实素材/几何能提供。
- **验证**：比较主体与背景的相对尺度、遮挡和边缘透视；检查最近距离及最大取景变化时，主体无意裁切、消失或穿过近裁面没有发生。
- **修复**：移除为凑构图叠加的多重 scale/zoom；改变机位与视角组合，重验字幕和关键部位；检查最终输出相机及裁切范围。
- **例外**：正交、长焦、dolly zoom 和夸张变形均可有意使用。只有工程要求真实比例时，失真才是确定违反约束。
- **依据**：SP-A、SP-D、SP-G、SP-H；修复次序为本 Skill 综合。

不要直接把一个软件的焦距数值复制到另一个软件就宣称镜头一致；传感器/画幅、视角轴向与最终构图都要核实。

## S04 光影和清晰范围支持关系

- **触发**：应落地的物体悬浮、阴影与运动脱节，或为“电影感”加模糊后看不清信息。
- **动作**：确定承接面、主光方向与物体离地关系；可用真实或简化阴影。先指定清晰焦点和阅读窗口，再决定是否使用景深及拉焦。
- **验证**：运动中接触和阴影关联，阴影不被意外截断；阅读段文字与产品关键部位清晰；拉焦是否确实把注意力交给了下一个对象。
- **修复**：先修承接面/位置/光源关系，再核实投射与接收及阴影覆盖；先修焦点，再减轻模糊，必要时关闭景深，用其他线索表达层次。
- **例外**：一般无影图形和大景深可通过其他深度线索成立；人物视频卡片必须满足下文悬浮要求，不能用此例外退回平贴。简化阴影可满足效果与性能目标。
- **依据**：SP-A、SP-D、SP-I；清晰窗口与诊断为本 Skill 综合。

**人物视频卡片的3D悬浮是硬要求。** 原视频从全幅缩成小窗或移到角落后，必须能看出卡片在底面前方。实现方式按风格选择：有方向/偏移/软硬关系的投影、受光边与厚度、透视/视差可以组合；至少形成一种在最终观看尺寸中明确可辨的空间分离关系。圆角、平面描边、人物轮廓边或无方向的一圈光晕，单独都不算悬浮。

先确定卡片与背景/承接面的关系，投影方向服从光向，距离和软硬服从卡片离面的关系；采用边缘光时同时让背面或底面退后，不能只描亮一个矩形。外部移动、缩放和倾转时，投影与边缘随卡片一致变化，不留固定在原位的影子；阴影绘在内容裁切之外。回到全幅原景时悬浮关系随落回画面的过程消退，不保留无来源的卡片影。

冻结终态检查能否读出离面，再查看转换中途和连续片段。看不出就调整光影、厚度、透视或背景关系，不能凭参数存在通过；文字与人物仍需可读，不以夸张倾斜或全局虚化换取立体感。人物自身是否描边另按背景条件判断。

## S05 给镜头一个目的，并指定主动作

- **触发**：相机、物体、标题同时乱动，或每镜都默认环绕/缓推。
- **动作**：写出相机要跟随、揭示、强调、交代关系或表达情绪中的哪一项；指定当前信息主要由主体动作还是镜头变化承担。安排可认出的起点与落点。
- **验证**：正常速度下能跟住主信息；诊断时暂时冻结相机或主体之一，比较混乱来自哪里。静止镜头也应纳入候选。
- **修复**：减少重复或抵消的运动；让辅动作配合主动作；若停止相机更清楚且不损失意图，就采用停留。
- **例外**：不跟随屏上动作的镜头仍可有清楚的叙事目的；不要求任何时刻只动一个对象，也不要求每次移动都缓入缓出。
- **依据**：SP-F；主动作记录与冻结诊断为本 Skill 综合。

## S06 同空间保持方位，换概念明确重置

- **触发**：同一场景/连续动作跨镜，或从实体空间切到新章节/抽象图解。
- **动作**：同空间记录轴线、相机在轴哪侧、主体屏幕运动方向和进出边。换概念则决定保留哪个身份/形状/位置线索，或明确断开再建立焦点。
- **验证**：看切点两侧与整段，左右关系和运动能追踪；观众能分清继续同一空间还是开始新概念。屏幕方向依据最终投影，不能只看世界坐标正负。
- **修复**：改同侧机位、用可见运动重新建立方位或补定位镜头；换章可用明确构图变化，删除导致误认同一空间的伪连续轨迹。不要直接翻转有文字的镜头。
- **例外**：越轴、反转与空间不确定可以表达迷失、冲突、观点改变；记录目的和预期效果即可。180 度不是所有 MG 转场的硬门槛。
- **依据**：SP-E、SP-F；章节重置及 MG 迁移为本 Skill 综合。位置/速度交接继续读 [转场](transitions.md)。
