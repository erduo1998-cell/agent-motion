# 画面构思与实现交接

完整影片的主方法见 [画面设计](film-direction.md)。在自己最好的构思上解决具体薄弱点；需要权衡实质不同的组织时再比较方案，不固定候选数量。构思与实现可以由同一作者完成，不因使用本参考而增加导演层或预算。

有独立实现者时，交接观看经历、主要画面轮廓、真实内容与材质、观察关系、关键动作和交接时段。目标框用来表达明确的投影位置，不代替内容构图。三维各角色有需要时用真实bounds落实；二维排版使用真实字面与局部尺寸。

实现中保留重要的场面与视觉变化。技术不足时选择保留观看意图的等价表达；场景、文字、相机分别有明确控制归属。用户锁定的分镜和局部修改沿用已有方向，不重做全片方案。
