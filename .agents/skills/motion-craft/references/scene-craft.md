# 从内容到场面

只强调清楚、克制、不碰撞，可能让生成停在熟悉的静态版式。本章提供构思方法，与 staging、编舞、层级、连续性原则相容；具体流程为本 Skill 综合，不是审美保证公式。

## 找到值得演出的变化

把 brief 的名词换成可观察的状态关系：

| 内容关系 | 可演出的变化 | 容易退化的做法 |
|---|---|---|
| 复杂中找到重点 | 竞争的尺度/方向受一个约束而形成主次 | 三张卡依次亮起，字幕说“聚焦” |
| 模块协同 | 分离对象沿共同轴对位、相互作用，成为整体 | 画三条箭头，模块互不影响 |
| 隐藏能力 | 从表面细节进入内部关系，再返回原对象 | 产品转几度，切到无关联图表 |
| 不同尺度 | 纹理或字形成为整体中可辨认的同一部分 | 整页缩放，背景/主体关系不变 |
| 语义推进 | 词组的位置、大小或连接方式随论点改变 | 每个汉字等间隔弹出 |
| 两种条件对比 | 相同视觉基准被不同条件改变 | 两边装饰、比例全不同 |

真实 UI 以真实状态为准；图形隐喻不能冒充产品功能。抽象 MG、动字和情绪片可以让形式变化本身承担表达。

## 为主事件设计三个状态

这里指“变化发生前 → 变化最有力的一刻 → 结果被理解”，不是固定片头、中间、片尾模板。

具体决定主焦点的屏幕位置和大小；哪个轮廓、字词、局部或颜色角色保持身份；变化由比例、方向、遮挡、聚散、重排或停顿中的什么造成；此刻哪些文字必须读完、哪些可退场。

三个状态若除了透明度几乎一样，应先检查有没有真正表达变化。淡入可以引入，但通常无法独立承担展开、连接、聚合、穿越的语义。

## 景别与构图形成句法

三分之四产品视图证明模型有厚度，却不必然让观众经历空间。

- 整体交代关系与方位；中景看相互作用；近景看接触、转面、纹理、字形或细节如何触发下一步。
- 不一定先放全景。有辨识力的局部可以提出问题，随后整体回答。
- 景别变化应在实际观看尺寸下可察觉。相机走很远、主体投影只动几像素时，查相机和主体是否抵消，重新定义屏幕结果。
- 大主体可以有意出画，识别轮廓和关键区域应在适当时刻交代。别因害怕任何裁切，把所有东西永久缩在中间。
- 阅读镜头可以固定。把幅度集中在有意义的揭示，通常比全片匀速漂浮更有力量。

宽屏实体可从占画面大部的细节退到完整物体，再观察局部动作；竖屏动字可从充满画面的关键词退到完整论点。这是尺度关系，不规定统一百分比或镜头数量。

## 同一场景状态推进

先建对象状态图，各段布局是同一图的不同排列。对象可从前景到工作面，组成整体，再成为下一镜的局部。对象移动、观察点改变、版式重排可以接力，无需每次全部淡出并重建舞台。

换概念时不强求伪物理连续，但要有明确接点：轮廓旋正成为图解边界，刚完成的结果扩成下一段空间，标题重音的位置被新主体接住。本次任务允许剪切时可明确硬切并重建焦点；本项目口播跨版式按 [连续交接要求](transition-construction.md) 重新设计接点，不能因初稿缺少关系便自动改硬切。

粒子、网格、环线只在说明路径、尺度、密度或节奏时使用；填满背景不等于有空间。

## 文字也有主事件

按职责区分视觉主句、解释句、注释/品牌，不要求永远同时出现。主句可暂时接管构图，动作后给它完整落定；解释句在主动作建立后出现，或先交代观看任务；注释不抢重心，不靠极小字号假装精致。

中文先分语义再分行，标点随所属短语；英文长词、产品名、数字单位单独量宽。字形表演先让人认出原句，再参与变化，最后恢复必要可读状态。中文大、英文小不是定律；两种语言同等重要时，应给同等阅读时间与光学重量。

## 静音中的强弱

清楚的建立动作可为更快的一组变化铺路；一次强变化之后停在结果，让观众获得理解回报。不要全部事件同长、同幅度、同曲线，也不要为快而压缩每句话。

可记录此次运动强度走向，如“观察 → 加速组织 → 短促揭示 → 停稳”；它只是当前情绪，不是统一四段模板。有音乐按实际乐句与重音，口播按语义，后配乐保留可调区。

## 排除换皮

在脑中去掉颜色、材质和装饰，动作设计还剩什么？若只剩同大小卡片入场、排队、出场，变化可能仅在皮肤层。反之，运镜复杂、文字巨大、变形炫目也不自动更好：应具体增加理解、情绪、记忆点或期待。
