# 排版与可读性：L01–L06

这里的规则把静态布局原则扩展到时间线；扩展后的检查方法是本 Skill 的工程化推导。来源编号见 [sources.md](sources.md)。

## L01：先确定观看顺序，再分配视觉权重

- **触发**：同屏多段文字、多个产品卖点或多个活动对象。
- **动作**：写清本节拍最先看什么、接着看什么；用尺度、位置、明暗、留白、运动起点中的少量差异建立关系。主次相同的对象可作为一个比较组。
- **验证**：在预期观看尺寸查看稳定画面，再以正常速度播放；能否不暂停就跟上所设顺序？主体出现时，装饰是否反而更抢眼？缩略图/灰度仅用于暴露竞争，不是通过证明。
- **修复**：先降低竞争对象的面积、对比或活动强度；必要时错开信息。别同时给主次对象加粗、发光、放大和弹跳。
- **例外**：对称对比、群体阵列、故意混乱可以有多个焦点，但需要观众能理解其作用。
- **依据**：LAY-A、LAY-B；时间维度为本 Skill 推导。

## L02：用关系排版，不靠随手给坐标

- **触发**：卡片、字幕、注释、图表或多镜头包装。
- **动作**：选少量对齐轴、基线和间距单位；相关内容靠近，组间距离更大。用共同背景/边界补充难辨的分组；可用留白解决时不加多余盒子。组件内部相对布局，整体再定位。
- **验证**：检查标题与正文、数值与单位、标记与解释是否会被误配；暂时去掉容器装饰后，关系是否仍清楚？
- **修复**：先修组内/组间距离和对齐，再决定是否加容器。中文字块按实际字形宽度排，别套英文字符数估宽。
- **例外**：光学居中可偏离数学中心；海报式自由构图可偏离网格，但要保留可说明的关系。
- **依据**：LAY-A、LAY-B、LAY-C。

本项目执行时，先测加载后真实字形及人物描边的可见范围，再明确文字组内距、不同语义组间距和容器内边距。不同组之间必须比该组内部更容易区分，不能让标签贴住人物描边、标题贴卡片边、单位挤入相邻说明；对齐坐标相同也要检查真实字面。元素无交叠只是底线，间距与视觉分组仍须在完整手机尺寸画面中检查。无法同时容纳时，重分区、重排或分时揭示，不统一缩小所有内容。

## L03：把留白和可用屏幕当成有限资源

- **触发**：满屏信息、底部字幕、平台控件遮挡、需要多个画幅。
- **动作**：从目标画幅建立可用区域，预留已知字幕、台标、UI 覆盖和裁切区；按主体/文字/辅助信息分区。给主角的运动方向留出空间。没有平台规格时，注明临时边距并用实际观看尺寸试看。
- **验证**：把平台遮罩或字幕区叠入预览，检查所有必需内容及运动范围；分别检查横版和竖版，不能只核对中心点。
- **修复**：重分区、换行、分时呈现或重新构图。长文优先语义断行；锁定文案不能悄悄删减。
- **例外**：有意出血的背景、装饰和过渡遮罩可以越界；阅读阶段的必需文字另行保护。
- **依据**：LAY-A、LAY-D。Adobe 的传统电视安全区有特定背景，不能直接当短视频平台通用模板。

本项目短视频实测补充：安全区保护的是重要文字、数值、脸部、关键手势及承载讲解的小窗，不是把整幅构图缩进一个小矩形。背景、纹理、装饰和非关键信息可以满幅出血；底部标题信息、右侧互动控件等遮挡区域只要求必读内容避让。需要时把讲解区移到上部、人物安排在其他可用位置，重新分配主次，不能统一缩放场景或整张视频作为修复。平台未明确时使用标注为暂定的遮挡预览；不把某片固定像素边距推广为各平台标准。

## L04：检查运动中的占位，而不只检查关键帧中心

- **触发**：多个对象经过同一区域、字号/缩放变化、旋转、推镜、父级变换。
- **动作**：按最终画面坐标评估随时间变化的可见范围 B_i(t)，考虑字形、描边/发光、遮罩、旋转、父级和相机投影。标记允许重叠的对象与时段，区分空间遮挡和信息压盖。
- **验证**：检查开始、结束、位移/尺度极值、两对象最近时刻、转场重叠峰值；对短促或非线性运动加密采样。起点和终点无冲突不能推断中间无冲突。
- **修复**：改路径、错开起止时间、缩短位移、调整层级或分区。若相机导致重叠，优先修相机或世界布局，不同时乱改两者。
- **例外**：标题进入遮罩、物体有意遮挡、形变中的重合有效；容器和自己的文字相交也不是碰撞。
- **依据**：ENGINE-V 支持投影概念；全时段占位验证是本 Skill 推导，见 [verification.md](verification.md)。

## L05：可读时间从文字真正可读时开始计算

- **触发**：动态标题、数据、字幕、段落说明或翻面 UI。
- **动作**：用真实字体、语言和最终文本排版。为必需阅读定义可读区间：内容足够完整、尺寸/对比足够、没有严重倾斜模糊或遮挡。出现时长不等于可读时长；字词依次出现可逐单位评估。
- **验证**：按真实用途播放：若有口播就配口播，不能因自己已知文案就判定来得及。检查数字单位、中文标点断行、最后一行和字库缺字。静音复看可检查视觉独立传意，但不强求所有包装脱离口播仍完整解释。
- **修复**：延长稳定段、提前完成字形出现、降低阅读期间运动、调整行宽或拆成多个节拍；必要时与已有总时长约束协调。
- **例外**：装饰文字或观众无需逐字读的纹理不按正文标准，但不能把必需卖点伪装成装饰以绕过问题。
- **依据**：LAY-B。没有“中文每秒统一读几字”的通用阈值；UI 的默认字号、英文行长也不是视频标准。

## L06：视觉语法跨镜头一致，注意力可以变化

- **触发**：系列视频、同片多镜头、横竖版或复杂数据包装。
- **动作**：复用标题级别、数值格式、强调色的含义、组内间距和标签位置逻辑。需要改变样式时，让改变对应内容变化，不要每镜重新发明组件。跟踪动态背景上的实际明暗关系。
- **验证**：把主要稳定画面并排查看，再播放衔接；相同角色是否无理由变字号、变色义或换位置？是否为了强调产生过多描边和光效？
- **修复**：收敛到现有样式变量；保留叙事上必要的变化。文字对比不足时先调整其背后的画面或底板，再加装饰。
- **例外**：章节变化或品牌刻意的多风格设计可改变语法，使用明确线索让观众重新定位。
- **依据**：LAY-A、LAY-B。针对网页 UI 且确有可访问性要求时，可参考 LAY-E 的对比规定；视频审美验收不能用一个对比数值替代。

## 本项目口播与资料包装的稳定阅读默认值

两轮实测都否定了无动机的斜字、斜标签或歪框。同类包装的阅读状态默认保持水平；不要为“动感”给所有元素叠旋转。用户明确要求所有框水平时完整遵守；有依据的三维转面或用户指定斜版参考另按任务处理，运动中的透视不等于文字长期歪斜。

资料原页负责交代来源，重点层负责当前阅读。原页正文与新增说明不得在同一区域形成两层可读文字叠压：读原文时把新增标题/注释放在独立区域；读提取结论时将原页文字退出该阅读区域、遮罩隔离或退为不可抢读的背景，保留来源身份。只把原页略微调暗而仍与前景字相互穿插，不算修复。不要把当前需要读的证据一起虚化。数值、补充语和注释分别预留占位，不能在大数字下再压上一条遮住它的说明。阴影用于交代层距与分离，检查偏移、软硬和光向；长投影不是三维感的默认答案。

## 对齐服从角色与叙事

不要因实现习惯把全片都靠右、居中或套同一标题栏。围绕主体朝向、人物/证据位置和阅读路径选择共同轴线；各段允许构图变化，保持文字角色、分组和间距关系可辨认。某片否定无理由靠右，不等于禁止右对齐。图与字都需要成为焦点时可分时交接，不能靠缩小其中一方或随意摆满四角解决。

## 实景叠字的局部衬光与柔影

原景明暗和纹理复杂时，在文字真正经过和停留的区域看实际输出。仅加细描边、名义上高对比的字体或通过边界检测，都不能证明观众读得清。先选原景较安静区域；需要分离时，深字可配局部浅色柔和衬光，浅字可配局部深色柔影，颜色和范围服从场景。用渐变、羽化和受控衰减保留实景，让文字背后的纹理退出焦点；不要默认变成硬边大矩形、全画面泛白或长投影。

检查同一时点修改前后，以及文字移动经过的明暗极值；再看手机尺寸下的阅读段、人物脸部和相邻动作。人物独立层可保护面部，但不能把文字衬光截成意外硬边；衬光不改变描边的触发条件：保留人物原背景时不描边，替换背景时按人物规则制作，衬光不能替代需要的描边。关键文字仍读不清时调整位置、字重、颜色或衬光范围，而不是叠更多线条。

此方法来自财务口播的条件性纠正；纯色海报、资料页和已经清楚的文字不必统一加阴影。实景增强元素按内容选择真实道具或诚实示意，并匹配环境材质和配色；元素应表达责任、比较、变化等关系，不为填空而堆装饰。
