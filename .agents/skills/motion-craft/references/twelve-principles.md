# 十二原则的迁移边界

这套命名来自 Johnston 与 Thomas 的《The Illusion of Life: Disney Animation》（1981），总结的是此前长期的角色动画实践。本 Skill 核对了 Adobe 教育摘要 MO-H，未读取该书原文，不声称是原著译文。IBM 的图形迁移 MO-E 与实践者采访 MO-G 都说明：媒介和目标变了，规则需要重解释。完整来源见 [sources.md](sources.md)。

下表是本 Skill 的适用性判断。原则是分析工具，不要求一个镜头用满十二种技巧。

| 原则 | 用于 MG/UI/产品视频 | 不适用或需降级时 |
|---|---|---|
| 挤压与拉伸 | 用形变表达受力、弹性 | 精确产品、文字、刚体不默认揉捏 |
| 预备动作 | 给重大变化一个注意力准备 | 即时反馈不为表演拖延 |
| 演出与构图 | 安排主次、空间与视线落点 | 多中心构图需有明确目的 |
| 逐帧推进 / 关键姿态 | 先定关键状态，再求中间运动 | 自然模拟可向前求解 |
| 跟随与重叠动作 | 依据从属和惯性错开动作 | 无因果关系不硬加拖尾 |
| 缓入缓出 | 起停有意，速度可读 | 恒速、跟手、冲击、硬切另定 |
| 弧线 | 轨迹符合身体、铰链或空间约束 | 导轨、网格无需强行绕弯 |
| 次级动作 | 辅助动作支持主要信息 | 不与主动作争夺阅读时间 |
| 时间控制 | 表达重量、力度和叙事重音 | UI 毫秒 token 不决定镜头时长 |
| 夸张 | 强化关键差异和情绪 | 数据事实与产品比例不能乱改 |
| 立体与扎实的造型 | 保持结构、体积、受力可信 | 有意二维不强制改成 3D |
| 吸引力 | 形态清楚，表现有辨识度 | 不等于全都可爱、复杂或弹跳 |

落到制作时，按 [motion.md](motion.md) 选动作与曲线，按 [transitions.md](transitions.md) 设计交接，并在 [sequence-rhythm.md](sequence-rhythm.md) 的整体时间结构中验证。无音乐同样可以靠变化、因果、停顿建立节奏。

不要继承“所有动作必须缓动”“所有路径必须弯曲”“必须弹跳”之类绝对表述；IBM 的克制弹性、直轴和帧率偏好也只在采用其品牌语言时约束。技术能实现，不等于设计上应该使用。
