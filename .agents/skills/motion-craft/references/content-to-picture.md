# 把内容变成画面

## 从本片的内容长出意象

先找文字背后的物体、动作、关系和变化。源文案用于理解意思；除非用户要求逐字显示，不必把每一句说明都变成一张标题卡。品牌、地点、数字和操作信息应保持真实；虚构内容沿用项目的设定。

例如“把散落的收藏安排成一天”可以让收藏对象自身发生组织、排序和连接，结果承接它们此前的身份；也可以通过一个人的选择组织叙事。它不自动等于三张功能卡依次亮起。这个例子提供的是语义到动作的关系，不规定旅行类影片的布局、配色或镜头数量。

## 看见材料，再决定它的用法

图片的轮廓、真实 UI 的控件关系、标志的负形、字体的骨架，都能成为构图与运动的起点。先明确当前实际可用的材料，避免在设计里依赖不存在的图片或字体。需要真实品牌资产时使用正确资产；虚构应用可以自建设计。纯文字和纯图形的作品不必强行找图片。

精细感来自主题成立的内容：真实的操作状态、恰当的图形结构、可读的文字层级、经过选择的材质和边缘。背景编号、细线、噪点或漂浮装饰不是固定配额；它们需要在这幅画面里承担作用。

## 把版面当作动画的确定状态

写出重要状态实际应有的布局，让进入动作到达它。后续状态仍需要自己的阅读关系。这样动画不用凭一组位移数字猜内容最终会落在哪里。它是一种构建方法，不要求增加原稿的审片修正轮次。

中英混排按语义角色分组：中文主词、补充语、刊名、英文副标、元信息之间的重量由这幅画面决定。主词承担重音时，可以由字形、尺寸、留白、颜色或出现时机支持；不必每次都采用同一种放大方式。用实际字形检查所选字体是否覆盖中文、是否具有所需字重。不要把英文全大写的字距或字体搭配禁令直接施加给中文。

需要三维展示时，先排好内容内部关系，再把它放进空间。将阅读内容和承载它的实体、相机、遮罩分清责任：需要受光或转面的内容使用对应的三维实现；需要保持屏幕阅读关系的文字按设计绑定投影。引擎和层级服务表达，不要求所有文字都采用同一种建模方式。

## 围绕一个局部表达集中实现

长片可按语义单元拆解，使作者有精力处理该段的构图、细节和动作。拆分不等于各段互不相关：保留完整内容上下文，传递实际素材、品牌设定和必要的入出状态。连续 UI 要交接对象身份、位置、观察关系和速度状态；快闪要交接重音、视觉母题和节奏。没有声音时按信息与动作组织，不假设音乐会补齐。

委派仅在任务已授权时进行；小片段可以由同一个作者完成。无需为每个镜头规定同样的布局或过程。制作条件允许参考范例时，让作者能实际访问这些资源，而不仅收到一句“参考某某效果”。
