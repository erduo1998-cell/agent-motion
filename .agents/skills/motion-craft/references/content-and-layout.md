# 内容证据与可读布局

本章是根据实际初稿失败形成的设计方法，不是某个来源提出的通用定律。方法服务当前任务，不要求所有影片都变成解释图。

## 先有值得被拍摄的内容

抽象主题可以借一个小而完整的示范具象化。决定主体身份、相关属性、关系和目标状态；再决定镜头。几个不同领域的例子：

- 路线规划：同一组站点与道路，原先路径绕行，改变后出现可追踪的短路。观众看到哪段被替换、终点仍是哪一个；三个“规划/连接/到达”标签自己连线不构成这个证据。
- 折叠结构：同一块板、铰链、支点，折起后形成可承重的支架；中景交代部件，近景看铰链与接触，结果展示完整轮廓。随机小方块升空再排齐没有表现折叠。
- 文字论点：某个词的大小、位置或被谁遮挡承担语义；动作改变它在句子里的权重，并组成最终论点。这里字形本身就是内容，不必加无关插画来“证明”文字。

抽象示范要少而具体；不凭空编产品规格、数据或真实功能。若用户只允许既定文案，可用这些语义块与程序几何表达关系；没有必要把每个段落标题复制成一批“数据”。

### 从结果倒推

先确定最有力的结果画面：实物结构、实际界面状态、完成的画面、关系或论点。写出画面内真正承载内容的节点及关系。把这些节点倒推成前态，再把改变的属性写成动作；用同一身份说明变化。

结果可以抽象，但应比前态多一个观众能指出的关系/结构。设计海报时，要让字形、主图形与负形形成有意图的构图；给旧口号加圆点和角标不自动使它成为有说服力的成果。产品流程离开实体进入内容空间可以成立，但进出要交代所属，核心内容应仍符合这件产品的用途。

### 让前后关系进入实现数据

流程/解释片的每个主变化保留一份短映射，例如 `{op, sourceIds, resultIds, mapping, changedRelation}`。`op` 可以是分类、排序、比较、合并、变形或路径改变。后态的排列由该关系推导，连线锚到实际对象或组域；不能只连接后来出现的步骤标签。

多对一变化注明代表方式：保留逐项、叠层、代表项、数量、连续带或轨迹。源对象完成聚合后把位置/形状/强调传给代表项，而不是同时把全部重复内容缩小堆在同一个锚点。真正的结果若新增对象，要交代其由什么材料/关系构成；辅助说明可以独立出现。

这只针对片中声称完成的因果过程。纯文字包装、叙事剪辑或情绪镜头可以通过语义、方向与节奏转接，不要求所有新镜头的对象都由上一镜物理生成。

## 内部布局先于相机 fit

`fitRectTransform` / 相机 fitting 只能放大、缩小、移动当前形状。如果一条长句是 7:1 的扁条，把它放进竖画幅仍是扁条；如果内部已经重叠，放大后只是更大的重叠。

先选择适合语言和画幅的内容组织：

- 中文按完整语义分行，允许主词与补充词不同尺度；标点跟随其短语。不能为填高强行拆成孤字竖列。
- 英文保护单词；长步骤序列可以沿真实关系纵向或分段组织，完整序列的阅读布局不必是一条横行。
- 3D 结果面先朝向可阅读的观察区；再以主体实际部件求景别。不能为“立体感”把需要看清的表面一直侧过去。
- 内容少时可以留白。增加主次与方向不是用相机平移整片空白，或凭空增添陪衬。

### 整理是另一套坐标

混乱态和有序态分别生成。前态有意交错，不意味着结果也按同样的行距堆到分类锚点。

对可读词组先测尺寸，再排布。例如一列不同高度的项目：

```text
cursor = columnTop
for item in orderedGroup:
    item.x = columnLeft - item.localBounds.left
    item.y = cursor - item.localBounds.top
    cursor += item.localBounds.height + readingGap
```

多列的下一列起点来自本列最大真实宽度加间隔；不是固定步长碰运气。DOM 用实际排版结果，SVG 用字形 bounds，AE 用 sourceRectAtTime，三维用最终字形/部件 bounds。

如果重复实体代表同一信息，可以在动作中聚合为一个代表实体并保留数量依据；如果每个实体的差异重要，就为它们分配各自可辨识的空间。不要只改 groupId，仍把十个词叠成一堆，然后用标签宣布“清楚了”。

## 协调内容动作与观看窗口

对于一次主事件，先决定哪种运动承担表达：

- 对象正在显著重排时，观察窗口可稳住，等重排结果形成再揭示整体。
- 相机进入局部时，让该局部保留可追踪的依据；不要所有内容同时逃离焦点。
- 需要追踪运动对象时，镜头运动保持它可见，同时让参照物展示相对位移。

不要把每个事件框独立做 contain 再一律插值。若对象 bounds 正在扩张，自动缩小父级可能抵消内容的展开；若焦点切换跨度很大，直接插值可能横穿空白。先选择跟随、保持、穿越、切换中的一种，再求需要的落点。连续的运动不等于必须连续移动相机。

## 清楚的形状还需要清楚的动作

主动作有准备、作用与落定，少数从属动作错开跟随；不用全部对象等时启动等时停止。通向下一段的路径由语义和空间决定。完整阅读时停止不必要的漂移，主句之前的重复/背景词应退开、遮住或收纳到各自位置。以状态与布局保证清楚，不等渲染后再人工补洞。
