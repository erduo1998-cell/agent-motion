# 动态排版的关键画面示范

这是原创教学图，主题是《时间的重量 / THE WEIGHT OF TIME》与《潮汐 / TIDES》。它们示范可实际看见的构图决定，不是模板，不是外部作品截图，也不是连续动画或成片质量证据。

新做以字形为主画面的包装/MG时，用图像工具查看与当前画幅接近的一组；另一组供对照。不改变用户锁定的文案、配色、字体与内容。

- [竖向：《时间的重量》](type-time-weight.png)
- [横向：《潮汐》](type-tides.png)

## 从图里学习什么

**主字形承担画面形状。** 核心字/词可以成为视觉主体，完整论点由另一层语义文字承接。不是把整句用同一种字号排成两行，再加几条线。不要因为所有文案必须出现，就让所有文案始终以同一种角色同时在场。

**画面之间改变轮廓。** 示例先让重心悬置，再使同一字形下坠/越界，最后承重；另一组让字形与波带互相穿过，再撤到一侧。近/远、实心/轮廓、疏/密、重心移动只是可选手段；所选变化要与当前语义相合。没有必要每一帧都塞巨大字形。

**中英文是两套排版关系。** 中文的方形字面可以成为图形，英文保持词界，用短行/独立区域承担语义补充；英文不必复制中文的字形运动，也不需要变成角落小装饰。两种语言都必读时，各自给出完整阅读状态。

**留白有接收对象。** 空白为字形将要落入、波带将要通过、结论将要停留留位置。不要让观察窗口搬运没有内容的空白；也不要把所有字缩小来制造“高级留白”。

**同一形状为下一镜提供依据。** 大字的笔画、基线或一个被赋予含义的面可以承担跨段接点；内容发生变化时，保留一项可追踪的身份。若变化只属于情绪或修辞，不强求物理变形；本次任务允许硬切时才用该方法，本项目口播跨版式仍按 [项目转场要求](transition-construction.md) 连续交接。

## 怎样迁移到自己的稿件

挑出当前文案里真正值得成为主形状的语义核心，给完整句、补充信息和译名安排各自角色。设计少量有明显轮廓差别的落定画面，决定同一核心如何从前一个位置/尺度进入后一个关系，再安排动作时间。变化中的裁切/重叠可以有意，完整阅读时要解除。

从图中迁移的是角色分配、形状变化和衔接依据，不是《时间》《潮汐》的故事、颜色或具体物件。真实 UI 操作、采访字幕、科学比较或已有克制分镜不套用这套大字表现形式。
