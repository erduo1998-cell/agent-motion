# 整体空间与节奏：先设计整段的关系

本章是对来源中 staging、编舞、视觉清晰度、相机连续性原则的综合应用，不是一项经实验验证的通用视频公式。来源见 MO 系列、SP 系列及 [sources.md](sources.md)。

## 一条时间线协调五件事

多镜头项目不要先给每镜随机选特效。每个节拍同时想清楚：

| 维度 | 要确定的关系 | 典型冲突 |
|---|---|---|
| 内容 | 此刻观众新获得什么；与上一拍是什么关系 | 新信息出现时上一条还没读完 |
| 空间 | 仍在同一世界、进入局部、退回总览，还是进入新概念 | 镜头每次回到无关的“默认中心” |
| 注意力 | 从哪个可见位置/对象移交到哪里 | 相机推向左边，同时主标题从右边抢入 |
| 动作 | 谁启动变化，谁跟随，什么时候完成或继续 | 元素停住又启动，相机还在晃，转场先把结果盖住 |
| 声音 | 无声、口播、音乐或声音设计；哪些是实际存在的锚点 | 把假定的鼓点当已知，把读字时间让给拍点 |

小任务在工作笔记中用一句话串起即可；长片可用 [planning-examples.md](planning-examples.md) 的表格。不同镜头共享的主体身份、空间轴线、文字角色、运动风格和章节关系是持续状态，不在每个镜头重新随机生成。

## 先画空间关系，再选镜头

“空间”不只是 XYZ。需要同时考虑：

- **世界空间**：谁在谁前面，观察点在哪里，物体真实移动还是镜头移动；二维作品可以没有真实三维世界。
- **画面空间**：主体、标题、字幕与留白如何占据最后的矩形画幅。世界布局合理仍可能投影到一起。
- **叙事空间**：总览与局部、容器与内容、原因与结果、并列对比之间的关系。这些关系在二维作品里也能通过嵌套、遮罩和位置延续表达。

例如“总览 → 进入一个模块 → 展示内部过程 → 回到总览”，先决定观众如何识别同一模块，再选推镜/遮罩/剪切。跨越到完全不同主题时无需强行让不相干物体变形相接；允许剪切的任务可明确切换，本项目口播跨版式则按 [项目转场要求](transition-construction.md) 设计连续交接。

每镜给相机一个可解释的作用：揭示空间、跟随动作、展示尺度、转移注意力，或保持静止供阅读。运动量由信息密度和叙事决定；不是镜头动得多就更有空间。

## 按声音条件建立节奏

| 实际条件 | 主时间依据 | 怎么安排 | 不要做什么 |
|---|---|---|---|
| 无音乐、无口播 | 因果、动作完成、视觉阅读、停顿 | 用“建立关系 → 变化 → 看清结果”组织长短变化；让速度、位移、密度、明暗和静止形成节奏 | 等音乐才开始；把每镜做成等长模板；只靠鼓点式闪白 |
| 只有口播/字幕 | 真实语音的语义重音和句间结构 | 在关键名词/因果转折附近展示对应对象，留出理解结果的时间；沿用已锁定字幕/时间锚点 | 每个字都触发动画；为视觉整齐任意改口播时间 |
| 已有音乐 | 实际音频的乐句、重音、段落变化，加内容/可读性 | 挑少数重要动作或剪切对应音乐事件；其他动作形成铺垫、延续或休止 | 仅凭 BPM 假定所有强拍；让所有东西每拍同时跳 |
| 音乐稍后再加 | 已成立的视觉节奏 | 标出必需时长、可伸缩停顿和可微调转场；后期仅在弹性窗口内对齐 | 先承诺某首未提供音乐的精确踩点；整体倍速破坏阅读 |
| 音乐驱动/MV/舞蹈 | 用户指定的音乐结构或表演 | 声画共同设计，允许声音承担不可替代的结构 | 强求静音后仍保留全部情绪；把说明片规则套到 MV |

没有音频不阻塞视觉工作。不得凭空声称听到了重音；工具只能给波形/能量峰值时，标为候选节拍，还需听音或由可用音频分析确认其用途。

### 无音乐也成立的视觉节奏

先让观众建立一个关系，然后改变其中一个重要变量，再让结果有被看见的机会。重复动作可建立预期，随后有目的地改变幅度、速度、路径或数量。安静段可完全静止；不靠背景永动填满停顿。

不要把“建立—变化—结果”机械拆成每镜等长三段：连续追逐可以一直推进，数据揭示可能需要较长停留，短促强调可只占一个动作。整段应存在可感知的组织，而非所有镜头必须同一拍式。

### 后加配乐的优先顺序

先找已有视觉落点附近的可用声音事件；再调可伸缩停顿和动作起点；必要时重做局部路径/曲线。若用户锁定声音为主，则可重排画面，但仍要处理文案可读性。无法兼顾的真实冲突要说明具体时段及可选修正，不能同时宣称全部达标。

## 跨场景选择重点，不把一种审美套遍所有作品

| 场景 | 优先解决 | 可以有意保持简单 |
|---|---|---|
| 中文知识包装 | 语义分组、阅读段、口播同步、注释与主体的关系 | 二维、固定相机、少量强调 |
| UI 交互演示 | 状态身份、输入反馈、空间关系、响应速度 | 短路径、无弹跳、纯透明或硬切 |
| 3D 产品展示 | 体积轮廓、材质受光、接触/悬浮依据、揭示角度 | 标签固定屏幕、相机阶段性静止 |
| 数据/流程解释 | 对应关系、因果次序、标签稳定、尺度含义 | 同组同步、等速过程、正交视图 |
| 海报/MG/动字 | 构图、语言节奏、形状关系、张弛 | 平面色块、无景深、不模拟重量 |
| 叙事/音乐短片 | 整段情绪推进、视线/空间方向、动作与剪辑节奏 | 文字极少，必要时故意不连续 |

## 整段复看时要回答

看完目标片段，观众是否能识别主体如何从上一个状态到当前状态？能否跟住注意力迁移？相机揭示的信息是否值得它造成的阅读负担？画面的高密度动作之后是否给了理解机会？声音是加强结构，还是掩盖了本来不清楚的结构？

这些是评审问题，不是固定配额。用具体时间点和可见现象回答，不用“整体不错”带过。
