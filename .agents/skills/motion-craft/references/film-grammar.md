# 语义章节与视觉节拍

一段文案可以由多个画面共同表达。章节回答“这一段讲什么”，视觉节拍回答“观看在什么时候、因为什么发生变化”。二者不必一一对应。

## 快闪：让阅读穿过变化

把每句文字放到一个场景，做一次入场，停几秒，再转场，得到的是动效海报或解释型动字。它可以适合其他任务，但不能因为写了 flash、stomp 或 kinetic 就当作已完成快闪。

快闪中的一个意思可以经历几次有组织的形态变化。例如一段讲“潮汐”的刊物，可以从字形局部进入完整词，再让它沿同一方向复制成节奏，随后切到疏密反相的版面，最后由留下的一个词接住下一段。这里发生的是新的观看事件：尺度揭示、空间重排、密度反转与内容交接。单纯让背景粒子继续漂浮，不会把长期不变的版面变成快闪。

不必把每次变化都做成复杂转场。切、遮、推、重排、短暂落定各有作用；若每次都先淡出再淡入，变化会被拖成一串独立页面。前后画面可以通过相同的字、形、位置、运动方向或视觉重量保持联系。

阅读可以跨多个相邻画面完成。同一个关键短语保留识别线索并多次出现时，观众不需要每次重新读完；完整发布信息可以集中在一个合适的落点。把所有角落小字都按正文留足时长，会让快闪停滞。反过来，要求读的正文只闪过几帧，也不是有力的节奏。

没有音乐时，用动作的发起、撞击、换位、密度变化和短暂停顿组成可感知的节拍。先判断连续短段是否真的短促、有推进，再展开整片；不要先平均分完总时长后再给每一页加动效。节拍长短来自这支片的表达，不给所有项目规定固定镜头数或每镜秒数。

## 连续 UI：让观看追踪因果

UI 的画面变化来自状态推进，不靠不断换页制造剪辑数量。选择对象为何成为详情、哪次拖动改变哪个数值、保存反馈来自哪个动作，需要被连续识别。镜头可以在一次操作的准备、接触、响应、结果之间换取景，保留身份或空间关系即可；整片始终远看同一个面板，也不能充分展示交互和材料。

UI 小组件的响应时间与影片观看时间是两件事。不要因为演示片有20秒，就让一个简单点击等几秒才响应；可以让镜头在动作前建立目标，在动作后看结果和细节。三维同理：侧面几何存在只是实现事实，交付机位能否让人读到材料、边缘、层次和焦点才是观看效果。

## 先判断类型，再润饰细节

对快闪，先看真正改变观看的节拍如何连接；对连续UI，先看操作对象与结果能否被跟随；对产品，先看主体和材料是否被识别。静帧排版、平滑曲线和完整文件不能替代这些类型判断。选一个最暴露该问题的短段实际做出来，确认方法成立后才扩展；保留失败短段，针对同一关系修改，不重新抽一个无关风格赌运气。

本章由实际制作失败归纳，提供判断与实现方法，不宣称是一套经统计验证的普遍审美定律。
