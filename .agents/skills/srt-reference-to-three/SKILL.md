# SRT 分析与制作交接

本 Skill 先完成内容分析，再把实际产物交给本地 [Motion Craft](../motion-craft/SKILL.md) 制作。分析与制作是明确的先后阶段，不把“看完一部分 SRT 就开始写场景”当成已完成分析。

每个新片在独立工作目录保存输入、分析、工程与输出；续作和局部修订沿用用户指定的当前工程及合格资产。用户明确要求独立复测时，从本次提供的原视频、SRT、明确参考和当前规则重新创作，不读取其他轮次的工程、成片、分析、抠像缓存或历史对话，也不向其他任务索取旧答案；相同输入不自动视为续作。公共字体、通用数学工具与有权使用的参考可用。

## 完整读取分析规则与输入

从项目根执行：

```sh
node scripts/read-stage.mjs --stage srt --kind talking-head
```

纯 SRT 动画用 `--kind animation`。逐次执行返回的 `NEXT_READ`，直到 `END_READING`；每次工具调用只返回一页，不合批打印全部规则。该阶段完整包含 [语义、重点与时间](references/semantic-planning.md)、输入范围及原有制作计划的内容字段。未完整返回的页先补齐，不能只读标题或每节前几行。

读完整 SRT、用户原始要求与有效纠正，区分原片/原声和视觉参考，核实画幅、时长及保留范围。口播包装没有删改授权时保留顺序、内容与时间；仅有句级 SRT 时不编造逐字时间。涉及事实、总数和专名时先核上下文，缺失会改变内容且无法查明时只问具体缺口，继续不受影响工作。

## 交给制作的产物

将分析保存在当前项目已有的内容初审、`PLAN.md`、`timeline.json` 或对应分析文件中；没有时在本片工作目录建立一份内容分析。它是制作输入，不是额外的阶段打卡表，也不要求另做故事板或锚点图。

内容应能直接支持制作：完整内容结构与原时间对应；每段原意、视觉表达任务、屏幕重音及必要条件；人物/证据/素材需求；数字终值、列举成员与总结回调；开场与主要转折；用户最新要求及被替代范围；源文件和参考入口、声音条件与时码精度。保留完整原 SRT 的可访问路径，不用摘要取代原文。

若已有合格分析，先完整读取并核对本次有效要求，复用其内容，不重新生成另一份。仅分析任务交付该产物即结束；已授权制作时，随后让 Motion Craft **先完整读取此产物**，再从 `assets` 进入制作，不能仅接一句口头概括。

## 制作衔接与范围

制作按 Motion Craft 的“素材人物与背景判定 → 视觉方向与关键构图 → 连续样段、逐段扩展 → 声音 → 整片检查”阶段执行。每阶段在动手前完整读取其全部对应规则；动画阶段不得边写整片边补读。排版阶段不先定稿全片静态页，后续逐段把构图、动作与衔接一起完成。没有默认的逐阶段用户审批。

真人口播制作先建立与原片同步的独立人物层，再按实际背景决定描边：保留人物原视频背景时禁止人物描边；替换人物身后原背景时必须做宽而舒展的描边。原景收进小窗不改变这一条件；卡片仍须有3D悬浮层次，框内人物必须重新居中取景。完整条件统一在 [人物规则](references/talking-head-lessons.md#参考分工与人物层)，实现由 Motion Craft 对应空间与容器板块维护。已有合格抠像核对复用。仅有 SRT 的纯动画不适用人物抠像。完整细则按阶段进入，不在分析阶段提前装入全部排版、抠像、动画和渲染资料。用户只修声音、局部镜头或文字时保留其范围，沿用不受影响的分析及已确认内容。规则适用与优先级统一按 Motion Craft 入口执行。

三期新增纠错、字体海报研究仍在正式规则中，各期颜色、框形、画幅和具体秒数不推广成固定模板。原有制作要求由 [制作原则](references/production-foundations.md) 与其他参考按章节进入对应阶段；迁移与历史证据只在追溯来源时查看。当前结构没有启用已撤销的多 Agent 分段制作方案。
