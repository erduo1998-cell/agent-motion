# 口播包装实测规则

用于有真人原片、人物分层、资料页、历史序列或音效设计的任务。来源包括 2026-09-17 的测试2、测试3、混能训练与家校沟通四轮制作，以及新增红酒、黄金金融、财务三期的条件性纠正和耳总后续明确提出的口播必须抠像、按空间组织的要求；单片参数留在证据记录。后续用户明确要求优先。最近两轮的原话与落点见 已归档的历史来源记录（独立复测不读取），日常制作无需重读历史。

## 参考分工与人物层

多参考按维度组合：可取一支的文字入场、人物动作与音效，取另一支的字体排版和正式气质。快切是否合适取决于本片表达；庄重不等于动作声很轻或缺少关键重音。

真人口播包装必须先抠出持续运动的人物，建立同步原片底轨与独立透明人物轨道，再进行包装实现。人物轨可以是透明视频或原片加逐帧遮罩，不得用单张抠图、矩形裁切或已有平面叠字冒充完成抠像。已有合格人物轨可核对后复用。执行者不能自行判断“不需要空间效果”而跳过这一步；这是所有真人口播包装的基础，不再只在需要身后字时触发。

基本层序由后向前为：**原视频底层 → 身后包装层 → 透明人物层 → 前景包装层**。身后层承载文字、照片、资料或场景；前景层承载需要盖在人物前的元素。层序为可调度的空间基础，不要求每帧填满四层或让人物始终出现。保留底轨不等于每帧必须看见原背景；人物移位、缩小或换窗时，用设计背景/资料覆盖、遮罩或已具备的干净背景处理底轨原人物，避免双人重影和残留轮廓。

保留原实景时，底图与透明人物在同一源帧、裁切、比例和容器变换下重合；身后文字可夹在两者之间。全幅原景收为小窗时由同一容器连续变换，避免底图先移动、透明人物后追而露出双影。是否保留原景按 [参考与素材](reference-and-assets.md) 判断；实景文字分离按 Motion Craft 的 [局部衬光](../../motion-craft/references/layout.md#实景叠字的局部衬光与柔影) 执行。

**描边只由人物身后的背景是否被替换决定，不由抠像是否存在、窗口大小或包装多少决定。** 抠像仍是空间合成基础；它可以只用于遮挡、单独调光或保护人物，不能把“有透明人物层”当作必须显示描边的理由。

| 实际画面状态 | 人物描边 |
| --- | --- |
| 全幅保留人物原景 | 禁止 |
| 原视频连同原背景缩成卡片、小窗、圆窗 | 禁止；卡片自身的光影/边缘独立制作 |
| 原景调色、压暗、局部虚化，或在原景上/身后加字 | 禁止；这些不算替换原背景 |
| 人物被抠出，放到设计背景、资料、其他场景上 | 必须；轮廓宽而舒展 |
| 原景窗内的人物局部越过窗口，越界部分落在替换背景上 | 仅越界且背后已换背景的轮廓描边，窗内保留原景的部分不描 |

判断参照人物周围仍显示的来源背景，不看全片外层画布换没换色。原景窗放在彩色大画布上，窗内人物仍是原景，不得整圈描人。原景与替换背景交接时，描边随实际替换区域同步揭示/收回；禁止在原景还完整时先整圈亮边，或原景已恢复后继续留边。底轨、人物、轮廓共享源帧与取景，局部越界不得复制第二张脸。

空间须在最终画面中可见：人物遮住身后元素，前景与人物有明确先后，层间相对移动或尺度变化体现距离。原景中的前后关系仍要保留；当文字或资料接管焦点时，将非焦点背景/前景降权或局部虚化，主讲人面部与当前阅读内容保持清楚。空间要求及卡片悬浮统一执行 Motion Craft 的 [空间与镜头](../../motion-craft/references/space-camera.md)；不能仅靠人物描边、圆角或填写不同z值认定空间成立。

进入构图阶段前核对同步人物层、来源背景状态和描边开关；换背景时再核对描边在真实画幅、手势和缩放中的可见性。原景段则核对没有残留装饰边。双轨只保留一份有效口播音频。抠像失败仍须修复；必须描边的换背景段不能静默撤边，原景段也不能为掩盖抠像瑕疵加粗边。

**人物进入任何新尺寸/比例的窗口，都必须做二次构图。** 人物的脸部与身体视觉中轴对准窗口水平中线，按真实头部、肩部和讲述手势调整内部裁切及比例；不能把视频矩形居中当作人物居中。保留完整头部、头顶留白和连续的颈肩关系，不能让脸或脖子卡在边缘，也不能变成过小的浮头或过大的贴脸。半身与关键手势是口播窗口的取景起点，人物近景等用户明确要求按指定范围处理。换形、缩放、移角后都重新检查；具体控制与过渡检查执行 [M02 内部取景](../../motion-craft/references/talking-head-motion-patterns.md#m02-将轮廓变化内部取景与容器移动分开)。

人物卡片必须从周围底面上浮起，不能只是原视频缩小后贴在平面上。卡片立体感由容器的阴影、边缘受光、厚度或透视等可见关系建立，与人物是否描边无关。保留原景的卡片禁止描人，但必须做卡片空间；换背景的人物卡片按条件同时处理人物轮廓和卡片空间。容器承接源直边，不能用羽化、描边、投影伪造源素材缺失的身体。

以下描边工艺仅用于上表必须描边的区域：先清除椅背、背景残留和遮罩噪声，再从稳定遮罩提取人物大形，生成独立着色外边带。边带必须宽、清楚、轮廓舒展；简化细碎凹凸，不逐点追发丝衣褶，不切掉真实头肩和主要手势。单纯膨胀alpha并继续显示原视频像素不是着色描边。描边颜色结合本片与相邻背景选择，不固定白色或历史片配色；阴影、羽化、容器框和衬光不能代替应有的人物边带。

检查人物最大/最小显示、手势峰值、位移和缩放的连续过程：交付尺寸与手机尺寸能辨认边带，不锯齿、不抖动、不意外裁断；有意遮挡的轮廓按遮挡关系处理。描边不得掩盖错误裁切。人物肤色、面部亮度、光向与背景相容；原景不因参考黑白而擅自变黑白，补光实际作用到人物，不能只在场景放灯而视频像素无变化。

本次用户明确修改时按其指定范围执行；其它片子的例外不外推。仅修声音等局部任务保持原范围，不追溯重做无关画面。

原片已有硬字幕时识别并保留其真实状态，安排新文字时避免冲突。测试3允许带硬字幕继续是本次试验豁免，不是未来一律保留、抹除或伪称已去字幕的授权。

新增逐字字幕、重点词和原片硬字幕是不同对象。用户要求去掉逐字字幕框时，移除对应新增字幕及底框，同时保留仍承担讲解的标题、话术与重点；若原片已压有字幕，按真实可处理范围说明。家校沟通片去字幕的决定不升级为全项目禁用字幕。

## 满幅构图与人物调度

短视频先保护重要文字、数据、脸部与讲解小窗的可读区域，背景和非关键装饰仍满幅铺开；不能整体缩进安全框。具体按 [排版与可读性](../../motion-craft/references/layout.md) 的 L03 检查发布遮挡与运动范围。底部被平台信息覆盖时重排讲解区和人物区，不只把所有元素一起上移或缩小。

人物大小与位置随情绪、讲解篇幅和主次关系变化：强调本人观点时可放大，读资料或话术时可缩到合适窗口，回到总结时再接管焦点。同一语义段保持稳定锚点，不因每句字幕或每张文字卡出现就换框、变形、左右跳；“时不时变化”不是按句触发的频率要求。转场也应让观众跟得上焦点，避免人物和主要文字同时跳向不同区域。

## 页内推进与段落衔接

口播驱动画面中的信息逐步出现。背景、标题、资料、标注、图表与数字可分时入场，让观众跟得上论证；避免页面所有内容同时出现后长时间静止。需要继续观看时，让焦点转移、资料局部展开或对象状态变化承担推进，不只用无关背景漂浮填时间。

人物运动要配合内容与空间安排，不为保持运动而每段左右滑一次。转场的动作和时长服务于前后画面，不能把所有段落套成相同模板，也不能让长转场抢掉信息的稳定阅读窗口。

本项目口播包装跨版式默认必须用连续对象、容器或运动带出下一画面，按 [转场实现](../../motion-craft/references/transition-construction.md) 落实；不能用“通用规则允许剪切”或旧片豁免省略本片衔接。用户本次明确要求硬切时按指定范围执行。此要求不扩成所有视频类型永久禁用硬切。

同一历史序列可保留相框或时间轴位置，随口播切换对应照片、年份和短说明；在不损害阅读时采用轻微推近等持续变化。不同年份的素材应对应实际事件，不能只改年份标签。

资料页先让观众认出来源与主题，再随口播揭示需要看的局部、高亮、关系和数字。比较与因果按原文逐步建立，不用一张“全部答案都在”的海报提前说完。稳定容器、渐进揭示、局部替换都是表达手段，不要求每页同时具备全部效果。

用户要求 K 线时，用蜡烛实体和影线等正确图形结构表达，并按口播阶段逐步生长、涨跌；不要用瞬间刷出的粗折线冒充 K 线。真实行情使用核对过的对应数据；仅作趋势讲解而无真实数据时，明确为示意，不把动画走势当作行情证据。

## 声音覆盖与力度分开设计

有声口播包装中，在时间计划阶段安排重要动作和语义的声音任务，而非最后统一加几声提示。用户明确无声、只保留原声或只改画面时遵守范围。

选择音色前，查本项目已核对的声音研究与本片参考；缺少适配依据、用户要求查当前做法，或反馈违和时，检索并查看可听实例与可靠制作资料，记录来源、用途及采用理由。不能仅凭训练记忆拼出几类音效便宣称符合当前审美，也不能把少数教程说成“所有人都喜欢”的统一标准。研究与声音选择落实到本片文字、标题、动作和情绪，不止保存一篇报告。

- **动作声**：对应重要人物移动、文字或素材入场、滚动、选择与落定。
- **重点提示**：帮助观众识别概念、数字或结论。
- **强重音**：少量用于震惊、反差或关键揭示，与普通提示形成可感知区别。

按事件区分音色与力度：细小文字变化、重要标题落定、人物移动、情绪转折不共享一套同音量的机械提示。先听清老师/主讲人的态度与重音，再让声音强化该语义；“不讨好、有边界”不自动配成敌对、滑稽或游戏提示。常规轻声也要有明确落点，强重击留给有内容依据的冲击。

先判断是覆盖不足还是力度层次不足，不能靠增加次数或整体调大音量替代设计。正式气质与有力度的局部强调可以共存；不按每个字机械打点，也不强迫每个重点都用重击。

需要人物快速放大配合冲击时，画面与声音共享事件时间，并检查起势、峰值、短暂停留和回落。音效瞬态、人物峰值与口播关键词是三个可核对的落点，代码共用时间只证明前两者可以一致，不自动证明逐字对齐。具体缩放比例、持续帧数和音色按片子决定。

保持原声可懂，检查最终混音的响度、峰值、噪声与主观听感。实际试听参考片及成片中重要动作和强重音；若当前工具只完成信号检查，如实说明，不称已听过或声音体验通过。

## 修订与交付

后续反馈通常补充已有要求。例如补强重击时仍需保留有效的移动/入场声音；调整人物白边不意味着撤销人物分层；允许历史框内硬切不等于撤销对转场质量的要求。明确被撤回或替代的部分，再做局部修改。

保留首稿与修订的可比版本。当前 MP4、播放器、说明、混音、配置和复现命令指向同一版本；不能在交付最新版时留下导出首版的操作说明。工程交换文件若只含原片与透明人物双轨，应明确该范围，不能称它包含所有 Three.js 包装。

旧测试2/3的历史记录包含抽帧、局部连续帧与媒体/音频测量，未见用户最终验收。新增混能训练最终版在原对话获用户认可；家校沟通最新修订在本次提取任务获用户明确确认通过验收。用户验收与助手的技术/视听检查分别记录；不能把认可外推为所有参数的通用标准，也不能把助手“已修好”当用户验收。

新增三期的用户纠正、正式规则落点与片级边界见 已归档的历史来源记录（独立复测不读取）。用户在提取任务中明确总体验收了这些片子的最新版；这项认可不改变早期快照的原始内容，也不将具体配色、字体和框形升级为永久模板。
