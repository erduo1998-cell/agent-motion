# 参考与素材

用于实际分析参考、决定画面材料和补齐素材时。参考中的题材与构图不是每段必须照搬的模板。

## 看参考并确定用途

新片或新的视觉设计默认先查项目 [公开参考分析库](../../../../reference-library/analysis/README.md) 与 [案例索引](../../../../reference-library/analysis/INDEX.md)，按语义需要选择开场、封面、人物、资料、图表、UI、空间或转场机制，完整读取所选案例的最终参数与分析结果；用户明确参考优先。这是可读的参考结果库，不分发原视频、原片抽帧或转写。也可使用自备且有权使用的案例，或本 Skill 的 [开场研究来源](opening-design.md) 与 Motion Craft 的 [公开来源索引](../../motion-craft/references/sources.md)。

分析报告提供机制与参数的历史观察，**读过报告不等于本次看过原片**，不能把其中观察改写为本次已观看或动态已验证。需要复刻具体动态、核验时序或据原片作判断时，使用用户提供或授权的原参考，或报告所列可访问公开页面，实际查看相关连续过程；未能取得或观看就说明范围，仅把分析用于机制启发，在本片实际输出中验证效果，不宣称完成参考片动态对照。索引只负责导航；不要把软件界面当作成片，也不为新片照搬循环回放轮数。

提取的是“谁带谁移动、何时交出重心、哪层遮挡哪层、停在哪里供阅读”。在当前计划记录案例 ID、源时间、借用机制、本片对应内容、需改动之处及验证落点；配色提取背景／主体／强调／次要信息的职责，按用户参考重新配色。中文词组、人物比例、目标画幅与可读时间必须重做适配。样板不取代口播必选抠像、人物边缘融合和主题开场规则。

记录每份参考的本地路径或来源，以及它负责的维度：排版、主体与空间、图像处理、人物出入、镜头、转场或声音。多个参考可以分别负责不同维度；发生冲突时按用户明确优先级和目标内容解决，不能默默选一个覆盖另一个。

查看全片结构与关键段，动作和转场必须看连续过程，不能只凭几张海报式截图推断。记录有用的时间点及观察：什么先出现、观众先看哪里、哪次状态改变引发运镜、前后如何交接。需要参考声音时检查相关音频；只检查信号或抽帧就只报告该范围。

提炼本片应继承的材质、字体关系、光色、密度与节奏，以及可变化的空间、主体和构图。横竖画幅不同，重新分配人物、正文、资料与留白，不压扁横屏布局或为了套参考裁掉手势和关键材料。

独立复测不把过去已验收的本地成片作为参考，不查找历史工程或历史任务。已吸收的通用纠错继续生效；具体色板、字幕安排、字体和框形按本次原片、语义及明确参考设计。人物描边按 [人物规则](talking-head-lessons.md#参考分工与人物层) 的背景条件执行：保留人物原背景不描边，替换原背景才描边，不能因抠像或缩窗自动开启。

用户要求还原某个具体效果时，保留能证明该效果的参考段及本片同类动态片段进行比较。不要用“参考了风格”替代对所指动作的落实；也不因某片出现纸边、圆框或固定配色就将其写成全局风格。

## 原拍摄环境与复用边界

先判断原景的构图、光色、质感和可读区域。原景已经适合主题时，把它作为本片素材，在其上组织身后字、局部道具和前景；不要仅为了“做过包装”而整片换成设计底。需要读资料时可收为人物窗口，让解释背景接管，按语义再回到原景。具体背景色和窗口段数由本片决定。

同一次制作可复用已生成的合格素材与抠像；独立复测仅复用本次用户提供的原始素材、公共字体及通用工具，不能未经内容判断复制上一片完整场景/卡片布局。用户明确要求重新设计时，新写本片的视觉和状态组织，记录复用的是资产还是设计，避免把改标题与换颜色当作重做。

## 按语义决定素材

先查用户输入与当前项目可复用资产，再为缺口查找对应素材。选择图片、视频、Logo、报告、字体或模型之前，明确它在当前段落承担什么解释作用；纯排版和关系动画无需为了丰富而硬塞照片。

搜索需求由“对象＋事件/年份＋画面用途”产生。例如历史年份要找与对应事件有关的可核对资料；同一泛化油田图片换三个年份不等于三段历史证据。素材中的事实、时间、品牌、界面版本与口播是否一致，需要逐项核对；不确定时明确示意或换用可证实表达。

- 真实品牌、产品、Logo、报告、数据或界面优先从对应官方来源取得。已有真实素材可以直接用于纹理、平面或局部展示，不受 H3 的全 AI 生成限制。
- 自绘关系图和 UI 示意用于讲解时，保留正确语义并明确其性质；不要伪装成官方截图、真实报告原页或已核实数据。
- 图片按实际内容选择展示区域，保留必要身份、动作和上下文。不能因为下载或加载成功就当成可用，要看清晰度、裁切、比例与目标画幅中的识别度。
- 缺少证据材料时，优先选择诚实的文字或机制示意；影响核心结果的缺失再向用户提出具体问题。付费素材、外部生成或上传私人素材仅在本次授权范围内使用。

重要人物、机构、研究或事件首次成为论证主体时，检查是否需要可辨认的肖像、身份、原页或事件材料来建立对象；只有一个姓名标题未必能让观众理解。转写中的专名先核上下文，再搜素材。没有适合或可用素材时明确采用文字/机制示意的理由，不捏造照片或原页。

素材搜索与验收同时包含主体、行为和修饰关系。“喝酒时的心情”需要饮酒情境，“配餐”需要酒与食物的关系，不能只搜到任意表情或一盘菜就算匹配。主题主图先检查真实画幅中的类别辨识、轮廓比例和材质；泛化瓶子、抽象方块等不能在主视觉需要认出红酒/产品时冒充到位。

## 可追溯并可渲染

在当前任务的素材表中记录本地文件、来源、用途、对应段落、真实资料/示意性质，以及已知使用许可和限制。保留原件，裁切与去背景另存。仅为参考审阅取得的素材，不自动视为成片可发布资产。

渲染所需资源按可用工具和来源许可落到本地，核对文件可解码或可解析；遵守具体工具的媒体访问与下载边界，不为规避显示限制下载。检查中文字体覆盖与真实字重，避免实际导出时静默替换。最终场景沿用本项目的本地资源服务，不依赖临时网页链接或运行时远程字体。
