# Your inputs / 你的输入

Place your own video, complete SRT, and any permitted reference material here.
Files in this folder are ignored by Git except this guide. Use relative paths
in your prompt, for example `inputs/source.mp4` and `inputs/source.srt`.
Do not upload private footage or credentials in an issue.
